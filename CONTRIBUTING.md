# Contributing
For a reproducibility question, open an issue and include your MATLAB version,
the command you ran, the full error text, and whether `demo_fusion` works.
For numerical changes, explain the mathematical reason, include the random seed,
and compare against the current result on the same inputs. Do not replace legacy
paper data or claim improved performance without supporting experiments.
Run `addpath tests; run_tests` and `demo_fusion` before a pull request.
Contact: [research website](https://lhadjbenzater.github.io/).
